## Engineering change

`CosmosMigrationRunner.CreateValidatedContainerAsync` now validates the actual `ContainerResponse.Container.Id` as well as the returned `ContainerProperties` name and `/id` partition key. The History handle must match `MigrationHistory` before the Lock container is created. The Lock handle must match `MigrationLocks` before lease acquisition or migration execution. Lazy ID hydration uses the shared cancellation-aware response guard: cancellation is checked before/after hydration, cancellation takes precedence if the getter throws while cancelled, and unrelated getter failures propagate unchanged.
