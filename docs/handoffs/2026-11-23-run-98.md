# Run 98 — private-media cancellation boundary

**Date:** 2026-11-23  
**Platform phase:** API `in_progress`; Android and iOS `not_started`.

## Engineering change

The non-development fail-closed `UnavailablePrivateDriverMediaStore` previously ignored cancellation in all four interface operations and returned null/false even when the caller token was already cancelled. It now calls `ThrowIfCancellationRequested()` before returning its deterministic unavailable result in `StoreAsync`, `ReadAsync`, `IsOwnedAndCleanAsync` and `DeleteAsync`.

This preserves the fail-closed provider boundary: non-development private media remains unavailable until approved private object storage and malware scanning are configured. No provider, scan-cleared status, retention, consent or deletion policy was invented.
