## Work completed

A targeted concurrency audit found four direct API conditional replacements in `Program.cs` and five transactional-batch writes in the Driver/Rider reservation stores that trusted the ETag returned by Cosmos without first rejecting a missing/blank value. A null `IfMatchEtag` can omit the condition. The migration lease store was inspected and already validates both expected and returned ETags.

A shared `CosmosEtagPolicy.HasObservedEtag` now guards:
- RideOffer replacement
- Driver reservation promotion, expiry update and release
- Rider reservation promotion and release
- Driver profile update
- Union assignment audit-snapshot completion
- Legacy ride acceptance before reservation acquisition
- Ride aggregate replacement

Cancellation is checked before local ETag rejection. A missing ETag prevents the provider write. Union audit recovery throws rather than clearing a pending audit marker; other paths fail closed or return conflict. No persisted shape, partition key, API response contract, fare or dispatch policy changed.

Strict-mock tests cover null, empty, space and tab for all five reservation operations (20 cases), plus five shared ETag-policy cases. Existing valid-ETag controls remain.
