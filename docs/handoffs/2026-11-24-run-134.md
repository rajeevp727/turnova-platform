## Implementation completed

- `CosmosMigrationRunner.RunAsync` no longer trusts `DatabaseResponse.Database` directly. It reads the handle through `CosmosReadResponseGuard.ReadResponseResource`.
- The handle must have a nonblank `Database.Id` matching the configured database name using ordinal comparison. Missing, null, empty, whitespace or mismatched identity fails closed before migration containers are created or a lease is acquired.
- Cancellation is checked around both the response-handle getter and `Database.Id` identity validation. If either getter throws while cancellation is signalled, cancellation takes precedence.
- Existing database-create behavior, container/partition-key validation, migration lease lifecycle, successful writes, ride/dispatch/fare policies and historical records are unchanged.
