## Run 122 engineering change

Audit found that `CosmosDriverRideReservationStore.GetActiveForDriversAsync` validated a null DriverId collection before checking the cancellation token. That violated the cancellation-first behavior consistently used by the other reservation store operations.

The method now checks `cancellationToken.ThrowIfCancellationRequested()` before `ArgumentNullException.ThrowIfNull(driverIds)`. Valid DriverId batching, blank/duplicate filtering, Cosmos query shape, query-result identity checks and persistence semantics are unchanged.

Two deterministic tests cover:
1. Pre-cancelled token + null collection → `OperationCanceledException`, with no Cosmos calls.
2. Uncancelled null collection → `ArgumentNullException`, with no Cosmos calls.
