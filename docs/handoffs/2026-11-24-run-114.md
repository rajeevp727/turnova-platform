## Engineering change

Audit found that `UnionAssignmentWriter` and `UnionStatusUpdater` mapped selected Cosmos 404/409/412 responses to ordinary false/NotFound/Conflict results without rechecking whether the caller had been cancelled while the provider call completed.

The six catch paths now call `ThrowIfCancellationRequested()` before mapping those Cosmos results:
- Union assignment create 409, replacement read 404 and conditional replacement 404/409/412.
- Union status read 404 and conditional replacement 404/409/412.

A cancellation signaled at those boundaries now propagates as `OperationCanceledException`. Successful writes remain successful; non-mapped provider failures continue to propagate. No unconditional retry/upsert, API contract, schema, fare, agreement, ride lifecycle, dispatch or FIFO behavior changed.

## Deterministic tests
