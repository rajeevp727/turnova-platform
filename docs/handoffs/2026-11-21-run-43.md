## Engineering change

AUTH-API-052 closes a logout Authorization parsing gap. `AuthenticationHeaderValue.TryParse` is a generic authentication parser and accepts generic auth-param syntax that is not a valid RFC 6750 Bearer token. The logout endpoint now requires one Bearer field and validates token68 characters: ASCII alphanumeric or `-._~+/`, followed only by optional trailing `=` padding. Comma auth-params, embedded whitespace, leading padding and interior padding return HTTP 400 before TriSend. Valid opaque tokens with allowed punctuation and padding are forwarded unchanged; absent-header best-effort logout is unchanged.
