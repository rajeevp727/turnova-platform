## Engineering change

`CosmosMigrationDatabase.CreateContainerIfNotExistsAsync` now validates the create response's resource ID and partition-key path for every container, including those without TTL. A null or mismatched resource fails closed before the migration proceeds. TTL configuration also requires a non-null container handle and revalidates the read-back resource identity before any TTL replacement.

Deterministic cases cover:
- TTL read-back null resource and mismatched ID/partition path.
- Missing container handle before TTL read/update.
- Create response ID mismatch without TTL.
- Create response partition-key mismatch without TTL.
- Null create response resource without TTL.
