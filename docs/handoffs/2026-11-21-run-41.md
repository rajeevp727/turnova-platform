## Work completed — AUTH-API-050

The logout route now distinguishes an absent Authorization header from a present whitespace-only header. Previously, `IsNullOrWhiteSpace` treated both as absence. The route now checks header-key presence separately and requires every present value to parse as a non-empty Bearer credential. A present whitespace-only value returns HTTP 400 with no-store/no-cache before TriSend. A genuinely absent header retains best-effort logout without an upstream Authorization header. A supplied Bearer—including expired/invalid tokens—is still forwarded unchanged for TriSend to evaluate.
