## Finding

`CosmosRideOfferStore.TryReplaceAsync` forwarded the caller's expected ETag directly into Cosmos `ItemRequestOptions.IfMatchEtag`. If an empty/missing ETag reached this adapter, the SDK could omit the If-Match header and the operation could become an unconditional replace. That would violate the store's compare-and-swap contract. The in-memory adapter already returns false when the supplied ETag does not match the current non-empty version.

## Change

- Return false before any Cosmos provider call when `expectedETag` is null, empty or whitespace.
- Add strict-mock adapter tests for null, empty, space and tab, each verifying that no Cosmos call occurs.
- Preserve valid ETag conditional replacement and existing 412/404 false results.
- Add `COSMOS-STORE-007` to the API test plan and synchronize the progress, matrix and Project Brain. This is supplemental persistence evidence outside the 19-row denominator.
