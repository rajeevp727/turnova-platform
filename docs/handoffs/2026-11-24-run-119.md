## Run 119 implementation

Rider active-booking RequestHash is part of the persisted same-ride idempotency identity. The Cosmos resource guard and both acquisition stores now reject blank/whitespace RequestHash. Cancellation is checked before RequestHash validation so a pre-cancelled request still yields OperationCanceledException, matching the existing contract.

Added deterministic cases:
- Persisted Cosmos read rejects blank RequestHash.
- Cosmos acquire rejects blank RequestHash before calling Cosmos.
- In-memory acquire rejects blank RequestHash without storing reservation/audit state.
- Cosmos and in-memory acquire both honor a pre-cancelled token before blank-hash validation.

Valid same-ride replay, ETag conditions, transactional batches, audit events and expiry semantics are unchanged.
